# ☬SHΞN™ V2flair

سابسکریپشن **VLESS** تصفیه‌شده: جمع‌آوری از کالکتورهای گیت‌هاب، حذف تکراری و خراب،
تست واقعی اتصال (نه فقط پینگ TCP)، تست سرعت، پرچم واقعی کشور خروجی،
مرتب‌سازی بر اساس کیفیت و انتشار خودکار — هر ساعت.

```
GitHub Actions (hourly)
   ├─ collect  : ~40 منبع VLESS (گیت‌هاب + ساب‌های کاربر)
   ├─ parse    : اعتبارسنجی UUID/هاست/پورت/ترنسپورت، نرمال‌سازی
   ├─ dedupe   : حذف تکراری دقیق و معنایی (UUID+هاست+پورت+ترنسپورت)
   ├─ tcp test : پینگ TCP موازی
   ├─ xray     : تست واقعی HTTP از داخل پروکسی (204) + پینگ واقعی
   ├─ speed    : دانلود 512KB از Cloudflare و محاسبه Mbit/s
   ├─ geo      : کشور خروجی واقعی از cdn-cgi/trace + fallback آفلاین GeoLite2
   ├─ rank     : امتیاز ترکیبی سرعت/تاخیر/پایداری + Reality bonus
   ├─ verify   : عدم تکرار، عدم خرابی، برچسب درست
   └─ commit   : فایل‌های خروجی → برنچ main → Cloudflare Pages auto-deploy
```

هیچ wrangler یا توکن Cloudflare لازم نیست: پروژه‌ی Pages از قبل به همین
ریپو وصل است، با هر push دوباره بیلد می‌شود و `index.html` را نشان می‌دهد.

## خروجی‌ها (در ریشه‌ی ریپو)

| مسیر | توضیح |
|---|---|
| `/sub` | base64 — v2rayN، v2rayNG، NekoBox، Streisand |
| `/sub.txt` | متن خام، هر خط یک نود — Hiddify، Happ، sing-box |
| `/base64.txt` | همان base64 |
| `/stats.json` | آمار آخرین بیلد |
| `/` | صفحه‌ی وضعیت + ریدایرکت به مقصد نهایی |

نودها به ترتیب کیفیت (بهترین اول) مرتب شده‌اند.

## مقصد نهایی

انتهای `index.html` یک بلوک مشخص دارد؛ فقط همان یک خط را عوض کنید:

```js
const FINAL_URL = "https://t.me/aishervin/724";
```

صفحه ۲۰ ثانیه نمایش داده می‌شود و بعد به این آدرس می‌رود.

## راه‌اندازی

```bash
git clone https://github.com/aishervin/V2flair
cd V2flair
pip install -r requirements.txt
bash scripts/setup.sh                     # xray + GeoLite2 (فقط برای اجرای محلی)
python scripts/main.py --out .            # بیلد کامل
python scripts/verify.py .                # فقط اعتبارسنجی
python -m unittest discover -s tests -v   # تست‌ها
```

در گیت‌هاب هیچ تنظیمی لازم نیست؛ `GITHUB_TOKEN` خودکار است و
`permissions: contents: write` در ورک‌فلو ست شده. کافی است ریپو را به
Cloudflare Pages وصل کنید (اگر هنوز وصل نیست).

فقط جمع‌آوری و پارس، بدون تست شبکه:

```bash
python scripts/main.py --dry-run
```

## تنظیمات

| متغیر | پیش‌فرض | توضیح |
|---|---|---|
| `MAX_NODES` | `200` | تعداد نود نهایی (سقف ۵۰۰) |
| `MIN_SPEED_KBPS` | `800` | حداقل سرعت (kbit/s)؛ در صورت کمبود خودکار شل می‌شود |
| `MAX_LATENCY_MS` | `2500` | حداکثر پینگ واقعی |
| `TIME_BUDGET_SECONDS` | `1500` | سقف زمان تست |
| `XRAY_VERSION` | `v25.12.8` | نسخه‌ی Xray تست (۲۶ به‌خاطر حذف `allowInsecure` پین شده) |

## چرا خراب و تکراری نداریم؟

- **اعتبارسنجی سخت‌گیرانه:** UUID معتبر، پورت مجاز، هاست عمومی،
  پارامترهای سازگار با Xray، حذف تنظیمات متناقض (flow روی ws، reality بدون pbk و …).
- **حذف تکراری سه‌لایه:** URI یکسان، امضای معنایی، و یکتایی اکانت در خروجی.
- **تست واقعی:** ترافیک HTTP از داخل پروکسی تا `204` واقعی، سپس سرعت دانلود.
- **گیت کیفیت:** `verify.py` قبل از کامیت خروجی را دوباره پارس می‌کند؛
  تکرار، نود ناقص یا برچسب اشتباه = بیلد fail و بدون کامیت.
